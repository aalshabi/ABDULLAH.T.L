# سافر بوعي — Travel Consciously

**قناة تعليمية تكشف خدع السفر — الفنادق، الطيران، الترانزيت الوهمي، التقييمات المزيفة.**

## الفرضية الجوهرية

المسافر العربي يُخدع يومياً، ولا أحد يعلّمه. هذه ليست قناة "اكتشف الوجهات" — بل قناة **تعلّمك كيف لا تنخدع** قبل ما تدفع، قبل ما تطير، قبل ما تكتشف الفرق بين السعر المُعلَن وسعر التجربة.

## المحتوى

### خمس ركائز تحريرية

1. **كشف خدع السفر** — الفنادق، الطيران، الأسعار
2. **السياحة الداخلية** — تطوير المواقع السعودية (رؤية 2030)
3. **تحليل السمعة الرقمية** — قراءة التقييمات، كشف المراجعات المزيفة
4. **الأخبار والأزمات** — نشر سريع في نوافذ ضيقة
5. **الحجز الذكي وأدواته** — Google Flights، MCT، التذاكر القابلة للاسترداد

### الملفات المكشوفة (6 سكريبتات جاهزة)

- **الترانزيت الوهمي** — الكذبة الأكبر في الطيران
- **نفس الفندق، نفس الغرفة** — خدع بصرية في صور الفنادق
- **خدعة السعر الرخيص** — السعر الحقيقي ≠ سعر الحجز
- **كيف تقرأ تقييمات الفنادق؟** — 6 قواعد عملية
- **فخ نفس الفندق غير موسم** — الموسم يغيّر كل شيء
- **موسكو 25- بدون ثرمال** — تجربة شخصية

## بنية السكريبت المعياري

كل فيديو يتبع 7 محطات تحريرية مضبوطة:

1. **0:00–0:07** — Hook صدمة
2. **0:07–0:15** — التعريف: "أنا عبدالله، أشتغل في السياحة"
3. **0:15–0:45** — ألم تطبيقي (قصة شخصية)
4. **~0:50** — Hook ثانٍ
5. **1:00–2:00** — قواعد عملية (3–6 قواعد)
6. **2:00–2:30** — قفل السلسلة ("في الفيديو الجاي...")
7. **النهاية** — سؤال استفزازي
