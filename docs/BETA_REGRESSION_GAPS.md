# فجوات Regression للـBeta المغلقة

هذا الملف يوثّق الفجوات التي كشفتها Fixtures الصناعية في المرحلة الرابعة. لا يحتوي على نصوص
مستخدمين أو مقتطفات عروض أو evidence أو بيانات حساسة. لم تُعدّل توقعات الاختبارات ولم يُغيّر
محرك التحليل ضمن هذا العمل.

## ar-conflicting-prices

- التصنيف: `conflicting_prices`
- السلوك المتوقع: اكتشاف `multiple_prices` عندما يذكر العرض الصناعي سعرين نهائيين مختلفين.
- السلوك الحالي: يحتفظ مستخرج السعر بأول قيمة فقط، ولا يمرر ملاحظات الأسعار المتعددة إلى طبقة التعارضات.
- مستوى التأثير: عالٍ؛ قد لا يظهر تعارض مالي يحتاج إلى حسم قبل الحجز.
- اقتراح PR مستقل: إضافة جمع حتمي لملاحظات الأسعار المتعددة وتمريرها إلى `OfferObservations`، مع إبقاء Fixture الحالية كاختبار قبول.

## ar-conflicting-nights

- التصنيف: `conflicting_nights`
- السلوك المتوقع: اكتشاف `conflicting_nights` عندما يذكر العرض الصناعي عددين مختلفين لليالي.
- السلوك الحالي: يحتفظ مستخرج الليالي بأول قيمة فقط، ولا يمرر ملاحظات الليالي المتعددة إلى طبقة التعارضات.
- مستوى التأثير: متوسط؛ قد لا يظهر اختلاف في مدة الإقامة يحتاج إلى توضيح.
- اقتراح PR مستقل: إضافة جمع حتمي لملاحظات الليالي المتعددة وتمريرها إلى `OfferObservations`، مع إبقاء Fixture الحالية كاختبار قبول.

## سياسة التعامل

- تبقى التوقعات الأصلية داخل Fixtures دون تخفيف.
- تُشغّل توقعات الفجوات كاختبارات متوقعة الفشل حتى يعالجها PR مستقل.
- إذا بدأ اختبار فجوة بالنجاح، تفشل علامة expected-failure لتجبرنا على إزالة تصنيف الفجوة ومراجعة التوثيق.
- لا يُنسخ أي نص فعلي من الدفعة المغلقة إلى هذا الملف.
