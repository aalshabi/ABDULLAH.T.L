# تشغيل الدفعة الأولى من الـBeta المغلقة

هذا المستند قالب تشغيل فقط. لا تبدأ الدفعة ضمن المرحلة الرابعة، ولا تُسجل فيه نصوص العروض أو
بيانات المشاركين الشخصية.

## الهدف

- 10 مستخدمين.
- 50 عرضًا نصيًا.
- تغطية العربية والإنجليزية.
- استخدام عروض غير شخصية وغير سرية، أو عروض مجهّلة قبل الاختبار.

## معرفات المشاركين

المعرفات المسموح بها فقط:

`U01`، `U02`، `U03`، `U04`، `U05`، `U06`، `U07`، `U08`، `U09`، `U10`

لا تُسجل أسماء المشاركين أو أرقام هواتفهم أو بريدهم الإلكتروني أو أي بيانات اتصال داخل المستودع.

## معرفات الحالات

استخدم المعرفات من `C001` إلى `C050`. يجب أن يكون كل معرف فريدًا وأن يرتبط بمشارك واحد فقط.

## البيانات المسموح بتسجيلها

| الحقل | القيم أو الصيغة |
|---|---|
| Case ID | `C001` إلى `C050` |
| Participant ID | `U01` إلى `U10` |
| Locale | `ar` أو `en` |
| Category | وصف عام غير حساس |
| Result | `pass` أو `issue` |
| Issue classification | إحدى التصنيفات المعتمدة أدناه |
| Safe Request ID | اختياري، عند عرضه من استجابة التطبيق المعلّمة فقط |
| Synthetic fixture created | `yes` أو `no` |
| Follow-up | رقم Issue أو PR الإصلاحي، إن وجد |

## البيانات الممنوعة

- نص العرض الأصلي أو أي جزء منه.
- evidence أو مقتطفات قابلة لإعادة التعرف على العرض منها.
- أسماء أو أرقام هواتف أو بريد إلكتروني أو بيانات اتصال.
- بيانات دفع أو أرقام بطاقات أو حسابات.
- روابط خاصة أو روابط مشاركة مقيّدة.
- ملفات مرفوعة.
- Screenshots تحتوي نص المستخدم.
- أي بيانات سرية أو شخصية لم تُجهّل.

## تصنيفات المشاكل

- `missed_fact`
- `wrong_fact`
- `irrelevant_question`
- `missing_question`
- `contradiction`
- `locale_issue`
- `formatting_issue`
- `usability_issue`

## سير العمل لكل حالة

1. عيّن Case ID وParticipant ID مجهّلين قبل الاختبار.
2. تأكد أن النص غير حساس أو مجهّل، ولا تنسخه إلى أي ملف داخل المستودع.
3. نفّذ التحليل باللغة المحددة.
4. سجل `pass` أو `issue` فقط مع وصف سلوكي عام.
5. عند وجود مشكلة قابلة لإعادة الإنتاج، أنشئ Fixture صناعية جديدة لا تعيد صياغة نص المستخدم.
6. اربط الحالة برقم Issue أو PR مستقل عند بدء المعالجة.
7. لا تفعّل Feedback ولا تستخدمه لتخزين الحالة.

## سجل الحالات

استخدم نسخة مستقلة من [BETA_CASE_TEMPLATE.md](./BETA_CASE_TEMPLATE.md) لكل حالة، أو نظام تشغيل
خارجي آمن يحفظ الحقول المسموح بها فقط. لا تضف خمسين ملفًا فارغًا إلى المستودع.

## بوابة النجاح

- إكمال الحالات الخمسين عبر المشاركين العشرة.
- عدم وجود أي تسريب بيانات أو إدخال بيانات ممنوعة في المستودع.
- عدم بقاء حقيقة خاطئة عالية التأثير دون معالجة أو قرار إيقاف.
- تحويل كل مشكلة قابلة لإعادة الإنتاج إلى Fixture صناعية.
- عدم وجود ارتفاع متكرر في أخطاء `5xx`.
- بقاء Feedback معطلًا.
- إنشاء PR مستقل لكل إصلاح مبني على Fixture صناعية.

## معايير الإيقاف

أوقف الدفعة فورًا عند:

- اكتشاف تسريب بيانات أو حفظ نص مستخدم.
- ظهور حقيقة خاطئة عالية التأثير دون وسيلة احتواء.
- تكرار أخطاء `5xx`.
- تغير حالة Feedback أو `noindex` دون موافقة مستقلة.
